# Plant Manager (installable app)

This repo only hosts the built app at https://mcrowane.github.io/plant-manager/ (GitHub Pages).
Opening it shows a "Connect this device" screen; data is only available to devices connected from the private Plant Manager.

**Don't edit files here.** The source is in the private repo `McRowane/plant-business`
(`manager/App.html`, `app/`, `tools/build-app.js`), and its deploy workflow publishes here.
